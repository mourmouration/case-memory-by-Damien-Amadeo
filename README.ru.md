# Case Memory

Долговременная файловая память по юридическим делам и проектам для ИИ-агентов. Автор: Damien Amadeo.

[English](README.md) | [Лицензия](LICENSE)

Скилл сохраняет итоги работы, правовые позиции с источниками, открытые вопросы и уроки в Markdown. Память отделена от личных предпочтений пользователя.

## Режимы

- SAVE — сохранить итоги сессии.
- LOAD — восстановить контекст дела.
- RECALL — найти опыт по другим делам.
- COMPRESS — подготовить выжимку сессии (не уменьшает текущий контекст модели).
- CONSOLIDATE — упорядочить память после согласования.

## Установка

Скачайте ZIP репозитория через Code > Download ZIP, распакуйте и переименуйте папку с SKILL.md в case-memory. Устанавливайте всю папку вместе с references и scripts.

- Claude Code: `~/.claude/skills/case-memory/` или `.claude/skills/case-memory/` в проекте.
- Codex: `.agents/skills/case-memory/` в проекте.
- Claude с поддержкой загрузки пользовательских скиллов: загрузите ZIP с папкой скилла; постоянное хранилище дел подключается отдельно.
- Другие агенты: используйте их механизм Agent Skills либо явно попросите прочитать SKILL.md и связанные инструкции.

Перезапустите агента при необходимости. Совместимость с конкретными клиентами требует проверки. Для вспомогательного скрипта рекомендуется Python 3.8+, сторонние библиотеки не нужны.

## Работа

Откройте рабочую папку и попросите «case-memory SAVE» или «case-memory LOAD». При первом сохранении подтвердите создание `0.3. Memory/`. Используйте одну и ту же постоянную папку между сессиями. Не публикуйте реальные материалы дел. Скрипт только читает данные; агент может записывать их через разрешённые инструменты.

Проверки: `python -m unittest discover -s tests` из корня репозитория.
