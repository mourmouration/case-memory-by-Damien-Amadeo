# Example / Пример

В пустой тестовой рабочей папке попросите агента: «case-memory SAVE: учебный проект demo, согласовали структуру отчёта, следующий шаг — подготовить черновик». Подтвердите создание памяти. В новой сессии с той же папкой попросите «case-memory LOAD demo». Пример вымышленный; реальные материалы дел в репозиторий не включены.
