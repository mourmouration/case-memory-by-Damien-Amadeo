# Сверка со встроенной памятью Claude (`/areas/`)

Справочный файл скилла `case-memory`. Применяй правила совместимости из SKILL.md; операции Claude необязательны и используются только при наличии инструментов. Читается в SAVE, LOAD и CONSOLIDATE, только если в сессии есть инструменты `mcp__memory__*` и сверка нужна. Цель – `/areas/<дело>.md` остаётся указателем и не дублирует карточку.

## Когда сверка нужна

Найди файл дела в списке встроенной памяти (он обычно уже есть в сессии; иначе `memory_list` с `path_prefix: "/areas/"`), сопоставив по названию дела, номеру дела и полю `aliases`.

- Файла нет – сверка не нужна. Этим скиллом он не создаётся: встроенная память создаст его сама, когда пользователь упомянет дело в чате. В карточке: `**/areas/ сверено:** нет файла`.
- Файл есть и обновлён не позже даты «/areas/ сверено» в карточке – сверка не нужна.
- Файл обновлён позже либо строки «/areas/ сверено» в карточке нет – сверка нужна.

## Разбор файла

Прочитай файл (`memory_read`) и раздели строки на две группы:

- **указатель** – стороны, номер дела, суд, роль пользователя, статус, ссылка на карточку;
- **подробности** – позиции, документы, задачи, хронология, расчёты.

Отметь подробности, которых **нет** в карточке `projects/<дело>.md`: они могли прийти из обычного чата claude.ai.

## LOAD

Ничего не записывается. Если есть подробности, которых нет в карточке, – назови их одной строкой в сообщении LOAD и предложи перенести при ближайшем SAVE.

## SAVE и CONSOLIDATE

1. **План.** Какие строки `/areas/` переносятся в карточку, какие убираются как дубли, какая строка-указатель добавляется. План выносится на подтверждение вместе с остальными вопросами режима. Без подтверждения `/areas/` не меняется.
2. **Сначала карточка.** Подробности, которых нет в карточке, вносятся в неё и записываются вместе с остальными файлами режима. Подробность уходит из `/areas/` только после того, как она есть в карточке на диске.
3. **Затем `/areas/`.** Правки – `memory_str_replace` по строкам, не `memory_write` целиком: файл могли дописать другие поверхности. При конфликте версии – перечитай и повтори. Файл не удаляется.
4. **Указатель.** Добавь строку, если её нет:
   `- [stated] Полная память по делу – «0.3. Memory/projects/<дело>.md» в рабочей папке; здесь только указатель`
   Поле `description` в шапке файла приведи к содержанию: «… – указатель на полную память дела». В `sources` добавь `cowork`, если его нет.
5. **Отметка.** В карточке обнови строку `**/areas/ сверено:** <дата>`.
6. **Сбой.** Отказ записи по содержанию или иная ошибка – сообщи одной строкой и продолжай: `0.3. Memory/` от этого шага не зависит.

Сведения, которые встроенная память не хранит по своим правилам, в `/areas/` не переносятся ни в каком виде: перенос идёт только из `/areas/` в карточку.
